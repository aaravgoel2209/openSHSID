# OpenSHSID — English Documentation

> **OpenSHSID** is a modern re-implementation of the SHSID (Shanghai High School International Division) campus website: Q&A forum, knowledge base, direct messaging, Reddit-style postbar, an AI campus assistant named **Rei**, OCR document processing, and a LinkedClassroom (Moodle) course browser.
